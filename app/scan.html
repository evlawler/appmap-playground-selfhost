When the first appmap-scan run lands, this page shows the report it renders and the lifecycle of each finding. The CI job publishes these files under reports/<repo>/scan/:

SCAN.mdThe report: summary table, then one action item per 🔴/🟡 finding (where, expected, actual, evidence, done when).
findings.ymlOne record per finding with status (open, dismissed, linked, fixed), chain (finding → accepted → fix → fix-trace) and next_action. Decisions are made in the repository, not here.
appmaps/The gold traces and the probe recordings the scan read, so every cited recording opens in the tabs above.
scan.json{ commit, date, note }: which revision of the default branch was scanned.
